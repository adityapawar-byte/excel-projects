🛍️ Vrinda Store Data Analysis (Excel Dashboard Project)

This project analyzes the Vrinda Store 2022 sales data using Microsoft Excel. The goal is to transform raw sales data into an interactive dashboard that provides valuable business insights through charts, KPIs, and data visualization.

📌 Business Questions Solved
📈 Compare monthly Sales and Orders using a single chart.
📅 Identify the month with the highest sales and orders.
👨‍💼👩‍💼 Analyze whether Men or Women purchased more in 2022.
📦 Examine the order status distribution (Delivered, Cancelled, Returned, Refunded, etc.).
🗺️ Identify the Top 10 states contributing to total sales.
👥 Analyze the relationship between Age Group and Gender based on order count.
🛒 Determine which sales channel (Amazon, Flipkart, Myntra, Ajio, etc.) contributed the highest sales.
👕 Identify the highest-selling product category.
📊 Build an interactive dashboard with slicers for dynamic filtering and insights.
